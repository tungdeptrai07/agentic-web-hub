# AgenticWeb Research & Bounty Hub

**Hackathon:** Open Agentic Web Challenge (`$10,000` Prize Pool)  
**Spec:** Worldwide Agentic Web MVP Profile 0.3 (`cognizant-ai-labs/agentic-web`)  
**License:** MIT

## Conforming Artifacts
- `agent-manifest.json` — Public machine-readable index of published agent networks.
- `network.json` — Data-only multi-agent network definition (`triage_coordinator` + `fact_auditor`) with peer discovery policy.
- `runtime.mjs` — Pure in-browser agent runtime executing directly from visitor browser with BYOK (Bring Your Own Key) LLM configuration.
- `index.html` — Interactive web interface for running the local network and authorizing peer agentic sites.
